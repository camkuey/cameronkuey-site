# cameronkuey.com

Personal portfolio of Cameron Kuey: operations, AI builds, and creative work (photography, film, design). A static [Astro](https://astro.build) site that uses no client framework. The only JavaScript is a small inline script for the mobile menu, the lightbox and the click-to-load embeds.

## Run it

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # static output -> dist/
npm run preview   # serve dist/ locally
```

Requires Node 22.23.4 or newer (see `.nvmrc`).

## Structure

```
astro.config.mjs        site URL, sitemap, build.format 'file' (pages emit /slug.html), trailingSlash 'never'
public/
  fonts/                Jost 300–600 woff2 + OFL.txt (self-hosted, the only typeface)
  media/<slug>/         optimized images (WebP 480–2400w, AVIF 480–1600w) + logo-animation mp4
  og.jpg, favicon*, apple-touch-icon.png, robots.txt, resume.pdf
src/
  styles/global.css     the whole design system (colors, type, nav, gallery, lightbox, case study…)
  layouts/Base.astro    <head>/SEO/OG tags, header + mobile menu, footer, lightbox dialog, scripts
  lib/site.ts           helpers: page(), alt(), image manifest, menu, site constants
  data/
    pages.json          content of the 27 pages ported from the old Adobe Portfolio site (blocks in order)
    images.json         image manifest generated by scripts/process-images.mjs
    alt.json            alt text per image id
    internal-dashboard.ts  case-study content (stats, modules, stack, lessons)
  components/           Pic (picture/srcset), Gallery (justified rows + lightbox), Embed (privacy facades),
                        Blocks (renders a page's block list), Covers, CreativeNav, DashboardArt
  pages/
    index.astro         home
    operations.astro, ai-builds.astro, creative.astro, contact.astro, 404.astro
    case-studies/internal-dashboard.astro
    [slug].astro        every legacy page at its original path (/wedding-photography, /work, /home, …)
scripts/
  process-images.mjs    sharp pipeline: originals (kept OUTSIDE the repo) -> public/media + images.json
  extract-content.py    old site export manifest -> src/data/pages.json
  check-links.py        verifies every internal link/asset in dist/ resolves
```

The original images (about 800 MB) are not in this repo. To re-run the pipeline, point it at the export:
`EXPORT_DIR=../site-export npm run images` (then `npm run content` if the page text changed).

## Add a page

1. Create `src/pages/my-page.astro`:
   ```astro
   ---
   import Base from '../layouts/Base.astro';
   ---
   <Base title="My page" description="One-sentence summary for search and social.">
     <section class="wrap page-head"><h1>My page</h1></section>
   </Base>
   ```
2. If it belongs in the top nav, add it to the `nav` array near the top of `src/layouts/Base.astro` (and to the menu list further down in that file if needed). The old Creative sub-menu comes from `menu` in `src/data/pages.json`.
3. Images: drop them in the export folder, run `npm run images`, and render them with `<Pic id="…" />` or `<Gallery ids={[…]} />`.
   Alternatively, put already-optimized files in `public/`.

## Add a case study

1. Copy `src/data/internal-dashboard.ts` to `src/data/<name>.ts` and fill in the content: stats, problem, modules, stack, "What broke", "What I'd do differently", and screenshot labels. Sections whose arrays are empty are hidden.
2. Copy `src/pages/case-studies/internal-dashboard.astro` to `src/pages/case-studies/<name>.astro` and import the new data file.
3. Link it from `src/pages/ai-builds.astro` (featured card or a mini card) and, if relevant, from `operations.astro`.
4. Real screenshots: replace the "Screenshots coming soon" placeholders with `<Pic>` once they are sanitized (sample data, no personal info).

## Deploy: Cloudflare Pages

| Setting | Value |
|---|---|
| Framework preset | Astro |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node version | 22 — set the env var `NODE_VERSION=22.23.4` (or rely on `.nvmrc`) |

The sitemap (`/sitemap-index.xml`) and canonical URLs use `https://www.cameronkuey.com` (see `astro.config.mjs`).
The output fits Cloudflare limits: about 175 MB, around 1,600 files, and the largest file is about 4.5 MB.

## Notes

- Embeds (YouTube, Vimeo, Facebook, Figma, Adobe XD, Apple Podcasts) are facades: nothing third-party loads until the visitor clicks. YouTube uses youtube-nocookie and Vimeo uses `dnt=1`.
- Fonts: Jost, SIL Open Font License (`public/fonts/OFL.txt`).
